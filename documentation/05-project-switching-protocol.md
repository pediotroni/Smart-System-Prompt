# Project Switching Protocol

Switching changes active context; it does not erase project state.

1. Resolve project through `20-project-index.md`.
2. Update `21-active-context.md`.
3. Load project identity, state, and current task.
4. Retrieve decisions/findings/TODO only as needed.
5. Preserve previous project state unchanged.

Roles: PRIMARY, RELATED, REFERENCE.

Never fabricate an unregistered project.
